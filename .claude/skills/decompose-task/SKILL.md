# Декомпозиция задачи из файла

Путь к файлу задачи передаётся в промпте запуска агента. Файл результата агент создаёт сам.

1. Прочитай файл задачи (Read).
2. Определи, сформулирована ли в тексте файла задача: есть ли описание того, что нужно сделать, создать, исправить или исследовать, — цель или проблема, которую требуется решить. Пустой файл или файл из одних пробелов задачей не является.

   **Если задача не сформулирована** — верни ровно одну строку:
   `<имя файла задачи>: это не задача, декомпозиция пропущена`

3. **Если задача сформулирована:**
   1. Выполни Bash `date +%s` и запомни результат как время старта декомпозиции.
   2. Проанализируй задачу и подготовь декомпозицию:
      - исходная задача — краткая формулировка;
      - подзадачи — разбей задачу на понятные шаги, по возможности независимые друг от друга;
      - для каждой подзадачи — подходящие средства: инструменты, технологии, библиотеки, подходы;
      - уточняющие вопросы, если задача неоднозначна; если вопросов нет, укажи, что их нет.
   3. Создай файл результата (Write) с именем `<имя файла задачи без расширения>-decomposition.<расширение>` в том же каталоге, где лежит файл задачи. Расширение — такое же, как у файла задачи. Формат файла:

      ```
      # Декомпозиция задачи: <имя файла задачи>

      ## Исходная задача
      <краткая формулировка>

      ## Подзадачи и средства
      ### 1. <название подзадачи>
      Средства: <инструменты, технологии, подходы>

      ### 2. <название подзадачи>
      Средства: ...

      ## Уточняющие вопросы
      - <вопрос> — или «Вопросов нет».
      ```

   4. Выполни Bash `date +%s` и вычисли затраченное время в секундах (разность со временем старта). Если выполнить Bash не удалось — укажи «время не замерено».
   5. Верни ровно одну строку:
      `задача декомпозирована: <имя файла задачи> → <имя файла результата> (затрачено <X> с)`
