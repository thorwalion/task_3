---
description: Сканирует каталог tasks и для каждого .txt-файла задачи (кроме *-decomposition) запускает агента декомпозиции
argument-hint: [каталог задач]
allowed-tools: Glob, Read, Bash(date +%s), Task(task-decomposer)
---

Каталог задач: `$ARGUMENTS`, если аргумент передан; иначе — каталог `tasks` в корне проекта.
Дальше `<каталог задач>` обозначает именно этот каталог.

Выполняй шаги строго по порядку.

## Шаг 1. Поиск файлов задач

1. Выполни Glob с паттерном `<каталог задач>/*.txt` (файлы внутри каталога, без подкаталогов).
2. Исключи из списка файлы, чьё имя без расширения заканчивается на `-decomposition` — это уже готовые результаты декомпозиции.
3. Если каталога нет или подходящих файлов не нашлось — выведи в консоль ровно:
   `Задач для декомпозиции не найдено`
   и заверши работу.

## Шаг 2. Отчёт о найденных файлах

Выведи в консоль количество и названия файлов:

```
Найдено файлов задач: <N>
- <имя файла 1>
- <имя файла 2>
```

## Шаг 3. Запуск агентов декомпозиции

Выполни Bash `date +%s` и запомни результат как время старта всего процесса.

Запусти по одному агенту `task-decomposer` на каждый найденный файл: инструмент Task, `subagent_type: task-decomposer`. Все вызовы Task сделай в одном сообщении, чтобы агенты работали параллельно. Каждому агенту передай промпт (подставь реальный путь):

`Файл задачи: <абсолютный путь к файлу задачи>. Выполни декомпозицию по скиллу decompose-task: создай файл результата и верни итоговую строку отчёта.`

## Шаг 4. Итоговый отчёт

Когда все агенты завершатся, выведи их сообщения в консоль дословно, каждое с новой строки. Затем выполни Bash `date +%s`, вычисли общее затраченное время (разность со временем старта из шага 3) и выведи строку:

`Всего обработано файлов: <N>, общее время: <X> с`
